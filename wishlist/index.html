分享給朋友

朋友打開連結會看到唯讀的清單（只有「想要」的東西），可以自己勾「我買了」再傳給你。私人備註和誰帶過的紀錄不會放進連結。連結是現在的快照，清單改了再傳一次新的就好。

要分享哪些地區（朋友要去日本，就只選日本）

雲端設定

清單存在你的私人 GitHub 儲存庫（wishlist.json），和行事曆、吉伊卡哇用同一組設定，這台已經設定過的話會自動接上。修改只會存在這台裝置；按「⬆ 上傳」才會用這台的清單取代雲端，「⬇ 下載」會用雲端的清單取代這台，不會自動合併。

這個 QR code 裡有你的金鑰，掃完就關掉，不要拍照或傳給別人。
