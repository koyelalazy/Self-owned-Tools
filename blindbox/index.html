雲端同步

修改只會存在這台裝置。按「⬆ 上傳」會用這台的資料取代雲端；按「⬇ 下載」會用雲端的資料取代這台。兩邊不會自動合併，有還沒上傳的修改時「上傳」會變橘色。資料存在你的私人 GitHub 儲存庫（blindbox.json，圖片放在 blindbox-img 資料夾），和行事曆用同一組設定。手機網頁版：在電腦這裡按「給其他裝置掃的 QR code」，用手機相機掃就好。

這個 QR code 裡有你的金鑰，掃完就關掉，不要拍照或傳給別人。
